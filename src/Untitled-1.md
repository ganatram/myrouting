

  Forms 

       Controlled Fields      - uses state hooks to store & collect data.

       Un-Controlled Fields   - does not use state hooks to collect data (alternatively we use FormData API(native))

       Native Validation - provided by Browser - such as required,minLength,maxLength, pattern - provided by constraint validation api 
                           , not reliable semi or no support in some browsers , no uniformity in error notifications. 

       React Hook Forms- 3rd party library - can both collect data & do validation - uses FormData API under the hood.
